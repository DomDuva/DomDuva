## What I'm building

**[Vitreous](https://github.com/DomDuva/Vitreous)** is a mediator for .NET built on source generators. It finds handlers at compile time instead of scanning assemblies with reflection, so it works with AOT and starts about 31 times faster than MediatR in my benchmarks. It also has optional Redis caching and a trace UI for seeing what happens during dispatch.

```sh
dotnet add package Vitreous
```

I wrote about why I built it: [Why I built my own .NET mediator on source generators](https://domduva.com/blog/building-vitreous).
